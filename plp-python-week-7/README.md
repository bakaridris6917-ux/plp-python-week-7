# PLP Python Week 7 - File Handling

- `my_notes.py` - writes three notes to a file, appends a fourth, reads them back and counts the lines.
- `my_notes.txt` - the file generated by `my_notes.py` (4 notes).
- `report_builder.py` - reads `hubs.csv`, counts passed and failed learners, calculates the average score and writes `report.txt`.
- `hubs.csv` - the learner data (name, hub, score).
- `report.txt` - the report generated by `report_builder.py`.

## What would happen if `"a"` was changed to `"w"` in Question 1?

Mode `"w"` erases everything already in the file before writing, so the first three notes would be wiped out and `my_notes.txt` would contain only "I added this later". The program would then print 1 line instead of 4.
